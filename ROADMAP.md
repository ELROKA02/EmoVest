# EmoVest roadmap

This roadmap describes the direction of EmoVest, not a delivery promise. We prioritize changes that make the journal more useful without compromising privacy, reliability, or responsible positioning.

## Now

- Improve the desktop journal, account management, and performance review.
- Make emotional insights clearer, optional, and easier to verify against the original trade context.
- Strengthen Windows release validation, update flows, backups, and recovery.
- Improve accessibility, documentation, and the contributor experience.

## Next

- Import trades from common broker and platform exports.
- Improve EVA's ability to guide multi-step journal review without presenting advice as fact.
- Build a personal behavioral model from the trader's own recorded history.
- Add focused dashboards for recurring emotional and operational patterns.

## Exploring

- Broker account synchronization, with privacy and user control as non-negotiable requirements.
- More portable import/export workflows.
- More documentation and product material in English.

## Help wanted

Issues labelled `good first issue`, `help wanted`, `documentation`, or `accessibility` are the best places to start. If you do not see a suitable issue, open a discussion issue explaining the contribution you have in mind.

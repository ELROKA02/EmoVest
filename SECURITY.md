# Security policy

## Supported versions

Security fixes are applied to the latest released version of EmoVest.

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected vulnerability, especially if it could expose trading data, local files, credentials, or the desktop API.

Email the maintainer at **contactoemovest@gmail.com** with:

- a clear description of the issue;
- steps to reproduce it or a proof of concept;
- the affected version and operating system; and
- any suggested mitigation, if available.

We will acknowledge the report, assess its impact, and coordinate a fix before public disclosure. Please allow reasonable time for a response and remediation.
